## Independent experiments

These public examples explore general software and AI concepts using fictional scenarios. Each repository explains what it demonstrates, how to run it, and its limitations.

| Example | What to explore |
| --- | --- |
| [AI Workshop Kit](https://github.com/dgoetz365/ai-workshop-kit) | A facilitator guide, learner workbook, practice scenarios, and review rubric. |
| [Service Desk Assistant](https://github.com/dgoetz365/service-desk-assistant) | Evidence-based answers and reviewable drafts for a fictional bicycle repair shop. |
| [Copilot Studio Workbench](https://github.com/dgoetz365/copilot-studio-workbench) | Conversation topics and a lookup API for a fictional print desk. Tenant integration remains unverified. |
| [Publication Workbench](https://github.com/dgoetz365/publication-workbench) | Draft review and published editions for a fictional arts program. |
| [Community Events Hub](https://github.com/dgoetz365/community-events-hub) | Connected records and event coordination for a fictional maker collective. |
| [Staffing Scheduler](https://github.com/dgoetz365/staffing-scheduler) | Volunteer assignments and schedule changes for a fictional science exhibition. |
| [Data Sync Workbench](https://github.com/dgoetz365/data-sync-workbench) | Reviewable imports that preserve local notes in a fictional library catalog. |
| [Workflow Desk](https://github.com/dgoetz365/workflow-desk) | Equipment requests and inventory constraints for a fictional community workshop. |

These are self-contained learning and portfolio projects. Their tests describe the examples' behavior; they do not verify any other system.
